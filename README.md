# PL-ASSIGNMENT

**Assignment 1 – Pizza Bill Calculator:** This C++ program takes the pizza price and quantity from the user, calculates the total bill by multiplying both values, and displays the final amount.

**Assignment 2 – College Canteen Bill:** This C++ program takes the quantity and price of Tea, Coffee, Sandwich, and Vadapav, calculates the cost of each item, and displays the total canteen bill.

**Assignment 3 – Mobile Recharge:** This C++ program takes the recharge amount and GST percentage from the user, calculates the GST amount, adds it to the recharge amount, and displays the final payable amount.

**Assignment 4 – Car Fuel Cost Calculator:** This C++ program takes distance travelled, car mileage, and fuel price as input, calculates the fuel required for the journey, and displays the total estimated fuel cost.
